# Hermes Tray — 产品需求文档

## 1. 产品概述

**Hermes Tray** 是 [Hermes AI Gateway](https://github.com/Hermes) 的桌面伴侣应用。它以系统托盘方式运行，提供 Gateway 进程管理、API 代理、AI 聊天界面等功能，让用户无需命令行即可操作 Hermes。

**目标用户**：Hermes 服务的使用者（开发者、AI 爱好者），尤其是 Windows + WSL2 环境用户。

## 2. 用户故事

| ID | 角色 | 故事 | 优先级 |
|----|------|------|--------|
| US-01 | 用户 | 我想在桌面右下角看到 Hermes Gateway 的运行状态，而不需要打开终端 | P0 |
| US-02 | 用户 | 我想通过右键菜单一键启动/停止/重启 Gateway | P0 |
| US-03 | 用户 | 我想在一个聊天界面中与 Hermes 模型对话 | P0 |
| US-04 | 用户 | 我希望应用随系统启动，方便日常使用 | P1 |
| US-05 | 用户 | 我想在设置界面中配置 WSL 发行版、API Key、端口 | P1 |
| US-06 | 用户 | 我想在聊天中看到 Markdown 渲染（代码高亮、表格） | P2 |
| US-07 | 用户 | 我想知道自己的 API 用量统计 | P3 |

## 3. 功能需求

### F1 — 系统托盘 (P0)

| 编号 | 需求 | 验收标准 |
|------|------|----------|
| F1.1 | 托盘图标显示 | 启动后在系统托盘区域显示 Hermes 图标 |
| F1.2 | 托盘右键菜单 | 菜单包含：打开 Hermes、Gateway 启停、设置、日志、退出 |
| F1.3 | 状态指示 | 图标或菜单项反映 Gateway 运行/停止/错误状态 |
| F1.4 | 通知气泡 | 启停/重启操作后弹出 Toast 通知反馈结果 |

### F2 — Gateway 管理 (P0)

| 编号 | 需求 | 验收标准 |
|------|------|----------|
| F2.1 | 启动 Gateway | 调用 WSL 命令启动 Hermes Gateway |
| F2.2 | 停止 Gateway | Graceful Stop → Force Kill 两级停止 |
| F2.3 | 重启 Gateway | 组合停止 + 启动操作 |
| F2.4 | 健康检查 | 定期通过 HTTP 检测 Gateway 健康状态 |
| F2.5 | WSL 自动检测 | 自动发现可用 WSL 发行版，无需用户手动配置 |

### F3 — AI 聊天界面 (P0)

| 编号 | 需求 | 验收标准 |
|------|------|----------|
| F3.1 | 对话发送 | 用户输入文本并通过 API 发送至 Hermes |
| F3.2 | 流式响应 | 模型回复以流式（SSE）方式逐字显示 |
| F3.3 | Markdown 渲染 | 模型回复中的 Markdown 正确渲染（代码块、列表、标题、表格） |
| F3.4 | 代码高亮 | 代码块带有语法高亮和复制按钮 |
| F3.5 | 对话历史 | 同一会话内保持对话上下文 |
| F3.6 | XSS 防护 | 所有用户/模型内容输出前转义 HTML |

### F4 — 设置 (P1)

| 编号 | 需求 | 验收标准 |
|------|------|----------|
| F4.1 | API Key 配置 | 支持在设置页面配置 API Key |
| F4.2 | 端口配置 | 支持配置 Hermes Gateway 端口 |
| F4.3 | WSL 发行版选择 | 下拉选择可用的 WSL 发行版 |
| F4.4 | 窗口状态持久化 | 窗口大小/位置在重启后恢复 |

### F5 — 系统集成 (P2)

| 编号 | 需求 | 验收标准 |
|------|------|----------|
| F5.1 | 开机自启 | 应用自动注册为开机启动项 |
| F5.2 | Windows 安装包 | 提供 Inno Setup 安装程序 |
| F5.3 | 自动更新 | 检查新版本并提示更新 |

## 4. 非功能需求

| 编号 | 需求 | 指标 |
|------|------|------|
| NF1 | 启动时间 | 应用启动到托盘图标可见 < 3s |
| NF2 | 内存占用 | 空闲状态 < 50MB |
| NF3 | Gateway 响应 | 启动 Gateway 操作反馈 < 5s |
| NF4 | 跨平台 | 支持 Windows 10+ (x64)，WSL2 |
| NF5 | 离线可用 | 聊天界面和托盘功能在无网络时可用 |
| NF6 | 安全性 | API Key 本地存储，不向第三方发送 |

## 5. 发布计划

| 版本 | 范围 | 时间 |
|------|------|------|
| v0.1 (Alpha) | F1 + F2 + F3 (核心功能) | 当前 |
| v0.2 (Beta) | F4 (设置页面) | 下一迭代 |
| v1.0 (Stable) | F5 (系统集成) | 后续 |
